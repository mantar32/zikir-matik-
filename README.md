# Zikir Matik

Tarayıcıda çalışan, internetsiz kullanılabilen **zikir / salavat sayacı** web uygulaması.

## Özellikler

- 📜 **Seçilebilir salavat & zikir listesi** (salavat, sübhanallah, elhamdülillah, allahu ekber, tevhid, istiğfar, lâ havle, tekbir)
- ➕ **Kendi zikrini ekleme** — okunuşunu ve istersen Arapçasını yaz
- 🔢 **Sayaç diski** — diske dokun / tıkla ya da `Boşluk` / `Enter` tuşuyla artır
- 🎯 **Hedef ayarı** — çevresel ilerleme halkası dolar, hedefe ulaşınca titreşim + uyarı
- ↩ **Geri al** ve 🔄 **Nazik sıfırlama** (uygulama içi onay penceresi)
- 🔊 **Ses** aç/kapa
- 📊 **Günlük istatistik** (bugün / dün) ve saatli **günlük hatırlatma**
- 🎨 **4 tema rengi** (yeşil, lacivert, mor, toprak)
- 💾 **Otomatik kayıt** — tarayıcı hafızasında (localStorage) tutulur

## Kullanım

`index.html` dosyasını çift tıklayıp herhangi bir tarayıcıda açman yeterli.
İnternet bağlantısı gerektirmez.
